# CursoLIVRE

- ODS: 4 Educação de qualidade

O CursoLIVRE busca expandir o acesso a educação para aqueles que não teriam a possibilidade de cursar uma faculdade ou curso profissionalizante, procurando facilitar a especializaçõa para brasileiros.

Este projeto consiste em um CRUD utilizando o Java Maven como linguagem de programação orientado a objetos junto com o MongoDB para banco de dados NoSQL, onde será gerenciado cursos cadastrados no sistema. 

Dependencias utilizadas: 
 .Spring Web para criação de API Rest
 .Spring Data MongoDB para a integração do banco de dados NoSQL ao projeto
 .Lombok para simplificação do codigo
 .JUnit para realização de testes automatizados
 .Swagger para documentação do projeto

 Pré-Requisitos:
  .Java 21
  .MongoDB
